# Diabetes Prediction Project 🩺

A complete Machine Learning project that uses **Logistic Regression** and data visualization to predict diabetes based on medical diagnostic measurements.

## 📊 Project Overview
This project analyzes a medical dataset to detect whether a patient has diabetes or not based on key health metrics such as Glucose level, BMI, Age, Blood Pressure, and Insulin.

## 🛠️ Built With & Libraries
- **Python** (Core Language)
- **Pandas & NumPy** (Data Manipulation & Preprocessing)
- **Scikit-Learn** (Machine Learning Model & Data Scaling)
- **Matplotlib & Seaborn** (Data Visualization & Insights)

## 📈 Key Steps & Model Pipeline
1. **Data Preprocessing:** Cleaning data, handling missing values, and scaling features using `MinMaxScaler`.
2. **Model Training:** Training a **Logistic Regression** model using Scikit-Learn.
3. **Evaluation:** Evaluating model performance using accuracy scores and confusion matrices.
4. **Data Visualization:** Generating insightful charts (such as correlation heatmaps and feature distributions) to better understand the medical data.
